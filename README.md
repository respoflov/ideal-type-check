# 이상형 셀프 체크

나와 내 이상형을 나란히 적어 보는 기록장 PWA입니다. 섹션별 문항에 「나」와 「이상형」을 각각 답하고, 제출하면 보관함에 쌓입니다.

- 배포: https://respoflov.github.io/ideal-type-check/

## 주요 기능

- 기본 정보·외관·성격 등 섹션별 문항 (선택형·서술형)
- 「나」와 「이상형」 두 행을 나란히 적는 비교형 문항, "상관없다"·"기타"·"패스" 선택지
- 작성 중 내용 자동 임시 저장
- 제출 기록 보관함, TXT 파일로 저장

## 파일 구성

```
index.html             앱 전체 (HTML·CSS·JS 한 파일)
manifest.webmanifest   PWA 설치 정보
sw.js                  오프라인 캐시 서비스 워커
icon-192.png, icon-512.png   앱 아이콘
```

## 데이터 저장

작성 내용과 보관함은 이 기기 브라우저에만 저장되고 어디로도 전송되지 않습니다. 브라우저 데이터를 지우면 기록도 사라지므로, 중요한 기록은 TXT 저장을 권장합니다.

## 실행·수정

빌드 과정이 없습니다. `index.html`을 브라우저로 열면 동작합니다. `index.html`을 고쳐 다시 올리면 방문자는 새로고침만으로 최신 버전을 봅니다(네트워크 우선 방식).

## 홈 화면에 추가

- 아이폰: 브라우저에서 주소를 연 뒤 공유 버튼(↑) → 홈 화면에 추가
- 안드로이드: 브라우저 메뉴(⋮) → 홈 화면에 추가 또는 앱 설치
